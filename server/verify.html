Certificate Verification

Verify a certificate

Enter the certificate number printed on the document. To also confirm the file has not been altered since it was issued, attach the PDF as well.

The file is never uploaded. It is fingerprinted in your browser and only the fingerprint is checked against our records.

A match confirms the document is the one issued under that certificate number and has not been modified since. It is a tamper check, not a cryptographic identity signature.
